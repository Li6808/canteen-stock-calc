# 食堂出库计算器

**当前版本 V1.0**（2026-10-25）　·　[项目档案](项目档案.md)

按周食谱自动算出每天的出库量，**早晚餐合并为一段，午餐（营养午餐）单独一段**。

## 功能

| 页面 | 说明 |
|---|---|
| **今日出库单** | 选星期 → 自动算出该出多少斤/桶。分类分组，午餐黄底标色 |
| **周食谱** | 7 天 × 3 餐完整食谱，菜名可点击改，配料克数可编辑 |
| **一周计划表** | 行=食材，列=每天×（早晚/午餐），每格直接是出库斤数 |
| **食材档案** | 53 种食材，五大类，参考单价可就地编辑 |
| **用量统计** | 累计出库量与金额，早晚餐/营养午餐分列 |
| **月度汇总** | 按月汇总，两栏分列，各类小计等于总计 |

## 核心规则

- **人数分两套**：工作日 800 人、周末 200 人，可分别修改
- **各餐就餐人数占比**：早 35% / 午 100% / 晚 65%（可调）—— 早餐人少、午餐最多、晚餐较少
- **油按桶计**：早 1 桶 + 午 2 桶 + 晚 1 桶 = 每天 4 桶，不随人数变化
- **换算**：每份克数 × 该餐实际就餐人数 ÷ 500 = 斤
- **周末不设营养午餐**：早+中+晚合并为一段

## 用法

打开 `index.html` 即可，无需安装、无需联网。

- **手机**：浏览器打开 → 分享 → 添加到主屏幕
- **电脑**：直接双击 index.html
- **数据**：存在浏览器本地。建议每月点右上角「备份」导出 JSON

## 打印

出库单页 → 「打印出库单」→ A4 横向。含分类分组、段合计、营养午餐专项签字栏。
